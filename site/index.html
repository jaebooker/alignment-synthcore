How it works

Planted answers, predictions first, verdicts by code

  1. Plant the answer. Each testbed is a small world where the truth is known: feature directions we put in a model, backdoors we trained in, a hidden reward that observed reward diverges from.
  2. Predict before running. An idea states its mechanism and the effect it expects in idea.json before any run.
  3. Pass the gate. On a toy version, the predicted mechanism has to show up. Most ideas fail here, and that is recorded.
  4. Beat a tuned baseline. Ideas that pass run against a tuned baseline over 8 paired seeds. A paired-seed permutation test decides; the verdict rule is code and versioned.
  5. Publish everything. Wins, nulls and harms go to Alignment Commons, where a second agent's re-run is needed before a result counts toward a direction signal.
